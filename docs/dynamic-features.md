# Dynamic and server-side features

Inventory of everything on https://doctoradoia.dia.fi.upm.es/ that depended on the server
(WordPress/PHP) or on third parties, and how each one was handled.

Classification (migration spec, phase 22):
**A** recreated with static files / client-side code · **B** links to an existing external service ·
**C** would need a replacement backend · **D** kept as an intentional external dependency.

| Feature | Original implementation | Class | Static site | Notes |
|---|---|---|---|---|
| Contact form, registration, newsletter, application forms, login | — | — | — | **None exist** on the public site. The contact page lists e-mail addresses and phone numbers only. |
| Site search (`/?s=…`, `/language/en/?s=…`) | WordPress core search, reachable from the search form on the 404 page | **A** | `src/js/search.js` + index `/assets/search/<lang>.json` generated by the build | Same URL and same markup/classes as the Astra search template. For the queries checked (`tesis`, `thesis`, a word with no results) it returns the same pages in the same order as WordPress. Differences: no author line under each result (it exposed WordPress user names and linked to author archives), no pagination (10 pages per language), needs JavaScript (without JS the URL shows the home page). |
| 404 page | Astra 404 template | **A** | `dist/404.html`, `dist/language/en/404.html` (texts in `data/<lang>/system.json`) | The web server must be configured to serve them (Apache: generated `.htaccess`; nginx: see README). |
| Language switch (ES/EN) | Polylang | **A** | Static links between translations (`data/<lang>/pages/<key>.json` share the key) | Polylang's `pll_language` cookie is no longer set (it only remembered the last language). |
| `/language/en/` → `/language/en/overview/` | Polylang redirect (301) | **A** | `data/redirects.json` → `.htaccess` rule + HTML fallback page | |
| SEO metadata, JSON-LD, sitemaps, robots.txt | Yoast SEO | **A** | Generated by the build from the page JSON | Same values; the WebSite `SearchAction` was not kept. |
| Hero background video | Video Background plugin (jQuery) | **A** | `src/js/video-background.js`, video self-hosted | Same behaviour: muted autoplay loop on desktop, poster image on mobile devices (Spanish home; the English home had no poster). |
| Tabs, entrance animations, sticky header, off-canvas menu, scroll-to-top | Essential Blocks / Astra / Astra Pro scripts | **A** | `src/js/{tabs,animations,header}.js` | See site-audit.md §6. |
| Horizontal scroll of the schedule table | TablePress + DataTables (`scrollX`, everything else disabled) | **A** | Same wrapper markup, plain CSS overflow (no JS) | |
| Google Maps in the footer | `<iframe>` (Google) | **D** | Unchanged iframe | Third-party embed; it is the only external request of the site at load time. |
| External links (UPM, ETSIINF, Portal Científico, BOE, RUCT…) | links | **B** | Unchanged | Checked with `npm run check-links -- --external`. |
| Documents linked from upm.es | links to PDFs on www.upm.es | **A** | 2 self-hosted in `/documents/upm/`; 2 no longer exist at upm.es (links unchanged) | See documents-inventory.md. |
| Hot-linked images (fi.upm.es, muia/dia.fi.upm.es, templately.com) | `<img>` / CSS from other hosts | **A** | Self-hosted copies in `public/assets/images/` | Removes the dependency on hosts that were intermittently unavailable. The images belong to UPM sites (and one decorative template shape); self-hosting confirmed by the site owner. |
| RSS feeds (`/feed/`, `/comments/feed/`) | WordPress | **C** (not needed) | Not migrated | The site has no posts or comments; the feeds were only advertised in `<head>`. |
| Author archives (`/author/<user>/`) | WordPress | **C** (not needed) | Not migrated | Only reachable from search results. |
| Comments, REST API (`/wp-json/`), XML-RPC, admin, login | WordPress | — | Removed | Not public content. |
| Editing content | WordPress admin | — | Edit JSON in `data/`, rebuild | See README. |
